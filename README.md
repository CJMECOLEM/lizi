# 保质期检查

用于门店和仓库的手机应用：拍照识别商品的生产日期、保质期和名称，算出还有多久到期，并按颜色标出快到期的商品。另外还能扫码计数，以及连续识别文字。识别全部在手机本地完成（Google ML Kit），不需要联网。

## 功能

### 保质期（主功能）

1. 点 **拍照识别**，先扫商品条码（也可以点“没有条码，直接拍照”）。
2. 对准包装上的生产日期和保质期拍一张照片。
3. 结果自动保存，然后自动回到扫条码界面，接着检查下一件商品。底部会显示刚才的结果，点一下就能修改。

- 能识别的写法：`生产日期 2025.03.01`、`20250301`、`2025年3月1日`、`保质期 12个月 / 十八个月 / 3年 / 365天`、`有效期至 / 保质期截止 / 限用日期 / 最佳食用日期 / 赏味期限 / EXP 2027.08 / EXP 03/2027 / BEST BY`、`请于2027年3月15日前食用`、`MFG 01/06/2025` 等。
- 只印了到期日、没有生产日期的包装，直接用到期日。
- 到期日是最后有效日：包装上印了到期日就直接用；没有的话，按“生产日期 + 保质期 − 1 天”计算。
- 商品名称：程序先自动猜一行（优先用“品名：”后面的文字，否则选字最大的那行中文）。修改时，可以从识别出的文字里点选。
- 同一个条码会记住名称、保质期和单位。下次检查同一商品时，只拍到生产日期也能算出到期日。没有条码时，按完全相同的商品名称沿用参数。
- **商品 → 批次**：外层每个商品一张卡片，显示批次数及库存汇总。有条码按条码分组，无条码按名称分组；不同条码不会因为同名而合并，既无条码也无名称的记录独立保留。
- 点进商品后，顶部标签按生产日期区分批次；只有到期日的标签显示到期日期。下方按“到期日期及剩余天数、条形码、商品名、图片、生产日期、保质期、数量、单位”排列参数。可修改数量和单位、加减库存或删除当前批次。
- **入库数量**：新批次默认 1，首次单位为“件”，后续沿用该商品的单位。再次录入同商品、同生产日期、同到期日，已有批次数量加 1，并沿用已有批次参数。没有生产日期的记录按到期日匹配，不与已知生产日期的批次自动合并。修改已有批次参数是覆盖保存，不会额外加 1。
- **一键复制**：详情页的“复制当前批次参数”只复制所选批次的文字参数，可直接粘贴到聊天或表单中，不复制照片文件。
- GS1 条码或二维码里带有效期的（部分外箱和进口商品），扫完码直接入库，不用拍照。为避免停留在镜头里反复加库存，连续录入同一 GS1 条码时需点“继续扫同一条码（下一件）”。
- 标色按自然月计算：**1 个月内到期标红，2 个月内标黄，已过期标灰**。商品卡片取最早到期批次的颜色；只要有一个批次符合筛选条件，该商品就会显示，进入时默认选中匹配批次。筛选数量按商品计算，同一商品可能出现在多个筛选中。
- Excel / CSV 仍逐批次导出，增加数量和单位列；有临期筛选时仅导出匹配批次。不同单位的库存分别汇总，不做箱件换算。
- 升级时旧记录和照片保留，旧记录数量初始化为 1 件（旧版未记录实际库存，请按实际数量修正）。库存为 0 的批次仍保留，可修改或删除。

### 计数

- 扫一次条码加 1。条码一直停在框里不会重复计数，要移出框再移入才会再加 1。
- 每一行都可以 +1、−1、改数量、填品名、删除，支持撤销上一步、清空，也能导出 Excel 或 CSV。
- 校验位不对的条码（通常是误读）会被忽略。
- 原计数页保留，与保质期批次库存独立，互不增减。

### 其他

- **闪光灯**：扫描时自动打开，离开扫描界面或切到后台就关闭，在设置里可以关掉这个行为。
- **连续识字**（设置 › 附加功能）：对准文字自动识别，并保存到识字记录。

## 目录结构

```
lib/
  main.dart            应用入口和底部导航（保质期 / 计数 / 设置）
  expiry/              日期识别规则和到期计算（纯逻辑，有单元测试）
  barcode/             条码校验、GS1 字段解析
  pages/               各个页面
  scan/                相机组件（扫码、拍照、连续识字）和文字识别
  services/            本地数据库、设置、导出、照片、提示音
  models/ widgets/
.github/workflows/     云端编译 Android APK 和 iOS 安装包
```

## 编译安装包

推送到 GitHub 的 `main` 分支后，会自动运行两个工作流，也可以在 Actions 页面手动运行：

- **Build Android APK**：在运行详情页底部下载 `lizi-apk`，里面是 `lizi.apk`，传到安卓手机上安装即可。APK 用调试密钥签名，每次编译的签名可能不同，更新前需要先卸载旧版本（卸载会删除手机上的记录，请先导出）。
- **Build iOS (unsigned IPA)**：下载 `lizi-unsigned-ipa`，用 Sideloadly 安装（见下文）。运行日志里有一步会检查中文识别模型是否打包进去了。

> 私有仓库使用 macOS 运行环境会按 10 倍速度消耗免费额度。

## 用 Sideloadly 安装到 iPhone

1. 在 Windows 上安装 [Sideloadly](https://sideloadly.io/)，以及**从苹果官网下载**的 iTunes 和 iCloud（不要用 Microsoft Store 版本）。
2. 用数据线连接 iPhone，在手机上点“信任此电脑”。
3. 打开 Sideloadly，把 `lizi-unsigned.ipa` 拖进去，输入 Apple ID，然后点 Start。
4. 在 iPhone 上：
   - iOS 16 及以上：打开 **设置 › 隐私与安全性 › 开发者模式**，开启后重启手机。
   - 打开 **设置 › 通用 › VPN 与设备管理**，信任对应的开发者。
5. 打开“保质期检查”，允许访问相机。

用免费 Apple ID 签名的应用 **7 天后失效**，需要重新安装一次，记录会保留。
